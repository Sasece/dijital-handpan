# Dijital Handpan

Tarayıcıda çalan dijital handpan. Telefonda dokunarak, bilgisayarda klavyeyle çalınır.

- 7 dizi: D Kurd, Hicaz, Celtic Minör, Integral, Amara, Pentatonik, Pygmy
- 5 kanallı loop kaydı, kanal başına ses düzeyi ve susturma
- Kaydı ses dosyası olarak indirme
- Ortam sesleri: deniz, yağmur, orman, yaz gecesi
- Tüm sesler tarayıcıda anlık üretilir, dışarıdan ses dosyası yüklenmez

Klavye: Boşluk = ding · 1–8 = tonlar · R = kayıt · P = çal/durdur
